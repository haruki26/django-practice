# アプリ利用ガイド

Wellness Foods 販売支援システムの利用方法をまとめたマニュアルです。ログイン後の基本操作や得意先管理、得意先別集計など、エンドユーザーが日常的に行う操作をここから確認できます。

## 本マニュアルの目的
- 主要画面の操作手順を簡潔に共有し、導入時のトレーニングコストを下げます。
- 入力時の注意点やエラーメッセージへの対処法を整理し、問い合わせを減らします。
- 機能追加や仕様変更のたびに本マニュアルを更新し、常に最新の情報を提供します。

## 追加済みガイド
- [ログイン手順](login.md): ログインからログアウトまでの操作とエラー時の対処方法を説明しています。
- [得意先管理の操作手順](customers.md): 得意先検索・登録・変更・削除・一覧の利用手順と画面遷移図をまとめています。
