# プロジェクト仕様書

このドキュメントは、販売支援システムの一部である得意先管理システムと得意先別集計システムの開発に関する仕様をまとめたものです。

## システム化対象業務

本プロジェクトでシステム化を対象とする業務は以下の2つです。

### 得意先管理業務

| 機能名 | 機能概要 |
| --- | --- |
| 検索 | 登録済みの得意先情報を1件表示する |
| 登録 | 得意先情報（得意先コード、得意先名、電話番号、郵便番号、住所）をもとに、得意先をシステムに登録する |
| 削除 | 登録済みの得意先情報を削除する |
| 変更 | 登録済みの得意先情報を変更する |
| 一覧 | 登録済みの得意先情報の一覧を表示する |

### 得意先別集計業務

| 機能名 | 機能概要 |
| --- | --- |
| 月別受注集計 | 得意先ごとの受注情報を月別に集計する |
| 年次受注集計 | 得意先ごとの年間の受注情報を集計する |
| 商品別受注集計 | 特定の得意先の受注情報を商品別に集計する |

## システム化機能

各業務をシステム化するために必要なシステムの機能と、その概要を以下に示す。 

### 共通

| 機能名 | 機能概要 |
| --- | --- |
| ログイン | 従業員番号とパスワードをもとにログイン認証を行う |

### 得意先管理業務

システム名：得意先管理システム

| 機能名 | 機能概要 |
| --- | --- |
| 検索 | 得意先コードをもとに、登録されている得意先情報を1件表示する |
| 登録 | 得意先情報（得意先名、電話番号、郵便番号、住所）をもとに、得意先をシステムに登録する |
| 削除 | 登録済みの得意先情報から検索を行い、該当する得意先情報を削除する |
| 変更 | 登録済みの得意先情報から検索を行い、該当する得意先情報（得意先名、電話番号、郵便番号、住所）を変更する |
| 一覧 | 登録されている得意先情報の一覧を表示する |

### 得意先別集計業務

システム名：得意先別集計システム

| 機能名 | 機能概要 |
| --- | --- |
| 月別受注集計 | 受注情報を月別に集計し、得意先コードごとに表示する |
| 年次受注集計 | 年間の受注情報を集計し、得意先コードごとに表示する |
| 商品別受注集計 | 特定の得意先の受注情報を検索し、受注情報を商品別に集計する。商品コードごとに表示する |
