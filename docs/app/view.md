# 画面設計

このドキュメントは、販売支援システムの一部である得意先管理システムと得意先別集計システムの画面設計をまとめたものです。

## 基本方針

- 画面はシンプルで直感的に操作できるように設計する。
- 入力項目は必要最低限に抑え、ユーザーの負担を軽減する。
- モダンで一貫性のあるシンプルなデザインを採用し、ユーザーエクスペリエンスを向上させる。
- 各画面には適切なバリデーションを実装し、データの整合性を確保する。
- エラーメッセージは具体的で分かりやすく、ユーザーが問題を迅速に解決できるようにする。
- レスポンシブデザインを採用し、様々なデバイスでの利用を可能にする。

## 画面一覧

| 名称 | 説明 |
| --- | --- |
| トップ画面 | システムのトップ画面 |
| ログイン画面 | 従業員番号とパスワードをもとにログインする |
| メインメニュー画面 | システムの各機能へのメニューを表示する |
| 得意先管理メニュー画面 | 得意先管理業務の各機能へのメニューを表示する |
| 得意先検索画面 | 登録されている得意先情報を表示する |
| 得意先登録画面 | 得意先情報を登録する |
| 得意先削除画面 | 登録されている得意先情報を削除する |
| 得意先変更画面 | 登録されている得意先情報を変更する |
| 得意先一覧画面 | 登録されている得意先情報の一覧を表示する |
| 月別受注集計画面 | 得意先ごとに月別の受注情報を集計し、表示する |
| 年次受注集計画面 | 得意先ごとに年間の受注情報を集計し、表示する |
| 商品別受注集計画面 | 特定の得意先について商品ごとの受注情報を集計し、表示する |
