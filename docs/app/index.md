# 開発ドキュメント案内

Wellness Foods 販売支援システムに関する開発ドキュメントをまとめています。仕様や画面設計、テーブル設計など、開発に必要な情報を以下のリンクからご確認ください。

## 各ドキュメント
- [開発環境ガイド](development.md): 使用技術や日常的に利用するコマンドを整理しています。
- [システム仕様書](spec.md): 得意先管理・得意先別集計システムの機能概要を記載しています。
- [テーブル定義書](tables.md): データベース構成と各テーブルのフィールド仕様をまとめています。
- [画面仕様書](view.md): 画面一覧と入出力項目、遷移方針を説明しています。

## 利用の流れ
1. 新しい要件や設計を確認するときは、まず本ページから該当ドキュメントへ移動してください。
2. 仕様変更が発生した場合は、app 配下の該当ファイルを更新し、Pull Request で共有してください。
3. ドキュメント更新後は MkDocs サイトを再ビルドし、最新情報を公開してください。

必要に応じて本ページにも追記し、ドキュメントの所在が一目で分かるように保ちます。
