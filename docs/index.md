# Wellness Foods 販売支援システム ドキュメント

## はじめに
Wellness Foods 販売支援システムのドキュメントへようこそ。本サイトでは、得意先管理システムと得意先別集計システムを中心とした仕様や運用情報を整理し、関係者の皆さまがいつでも参照できるようにしています。プロジェクトの目的である販売データの一元管理とリアルタイム活用を実現し、顧客満足度と業務効率の向上を図ります。

## ドキュメント構成
開発関連の情報はすべて `docs/app` 配下に集約しています。詳細な一覧は [app/index.md](app/index.md) をご確認ください。

### その他
- manual ディレクトリ: 操作手順やFAQを今後追加予定です。
- log ディレクトリ: 開発ログや決定事項を記録する予定です。

## 開発と運用の方針
- バックエンドは Python 3.13 / Django 4.2、フロントエンドは HTML・CSS・JavaScript を使用します。
- フォーマットや静的解析は `uv run task fmt`、`uv run task type` で統一します。
- ドキュメントは MkDocs + Material で公開し、docs 配下を単一の情報源とします。

## 今後の更新方針
- 先行して得意先管理・得意先別集計の内容を充実させ、受注管理機能は準備が整い次第追加します。
- manual や log ディレクトリに必要な情報が揃い次第、本トップページからもリンクします。
- 仕様変更や画面改修が発生した際は、app ディレクトリ内の関連ドキュメントを速やかに更新します。
