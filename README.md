# 販売支援システム モックUI

このリポジトリは、販売支援システムの得意先管理・得意先別集計機能を確認するためのモック画面を提供します。バックエンド処理やデータベースとは連携せず、画面遷移と入力体験を開発初期に検証することを目的としています。

## 環境セットアップ

1. 依存関係をインストールします。
   ```bash
   uv sync
   ```
2. マイグレーションと開発サーバーを起動します。
   ```bash
   uv run manage migrate
   uv run manage runserver 0.0.0.0:8000
   ```
3. ブラウザで <http://localhost:8000/> にアクセスします。

> :information_source: モックはスタブデータのみを扱います。フォームの入力内容は保存されません。

## 画面一覧

| 画面 | URL | 説明 |
| --- | --- | --- |
| トップ | `/` | モック概要とお知らせの表示 |
| ログイン | `/login/` | 従業員番号・パスワード入力でセッションを開始 |
| メインメニュー | `/menu/` | 各機能への導線を表示 (ログイン必須) |
| 得意先管理メニュー | `/customers/menu/` | 得意先関連機能へのショートカット |
| 得意先検索 | `/customers/search/` | 得意先コードで詳細を検索 |
| 得意先登録 | `/customers/new/` | 入力内容をプレビュー表示 |
| 得意先削除 | `/customers/delete/` | 削除対象の確認のみ実施 |
| 得意先変更 | `/customers/<コード>/edit/` | 仮の更新結果を表示 |
| 得意先一覧 | `/customers/list/` | モックデータ一覧表示 |
| 月別受注集計 | `/reports/monthly/` | 対象年月の集計結果を表示 |
| 年次受注集計 | `/reports/yearly/` | 年間集計結果を表示 |
| 商品別受注集計 | `/reports/by-item/` | 商品別の受注明細を表示 |

## ログイン方法

- 任意の従業員番号 (例: `E00001`) とパスワードを入力するとログインできます。
- ログイン中はヘッダーに従業員情報が表示され、「ログアウト」リンクでセッションを破棄できます。

## 開発メモ

- 画面スタイルは `psys/static/psys/css/app.css` にまとめています。
- モックデータは `psys/mock_data.py` に記載し、ビューから参照しています。
- 実装対象機能やUI項目の詳細は `docs/app/spec.md` と `docs/app/view.md` を参照してください。

今後は実データ連携、入力バリデーションの強化、自動テストの整備を予定しています。
